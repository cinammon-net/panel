# 🥚 Cinammon.net - Official Eggs Collection

Colección oficial de Eggs (plantillas de servidores de juegos, bases de datos y aplicaciones) mantenida por y para la plataforma **[Cinammon.net](https://cinammon.net)**.

Cada plantilla define imágenes Docker optimizadas, scripts de instalación modernos automatizados, variables de entorno y comandos de arranque compatibles con el panel de Cinammon.

## 🚀 Uso en Cinammon Panel

1. Abre tu panel de control de Cinammon en la sección **Eggs**.
2. Haz clic en **Importar Egg** (Import).
3. Pega la URL directa (`Raw`) del archivo JSON del egg que deseas instalar desde este repositorio:
   ```text
   https://raw.githubusercontent.com/cinammon-net/eggs/main/{categoria}/{archivo}.json
   ```
4. Guarda y el egg quedará disponible para crear nuevos servidores al instante.
